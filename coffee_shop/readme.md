# Cafe Ordering System

## Problem Statement

Build an in-memory ordering system for a cafe using plain Object-Oriented Programming principles.

The cafe offers:

### Coffee Types

* Espresso
* Americano
* Latte
* Cappuccino
* Mocha

### Sizes

* Small
* Medium
* Large

### Optional Toppings

* Whipped Cream
* Caramel Syrup
* Vanilla Syrup
* Chocolate Drizzle
* Cinnamon

## Requirements

* A customer can order multiple drinks.
* Each drink must have exactly one coffee type.
* Each drink must have exactly one size.
* Each drink can have zero or more toppings.
* The system must calculate:

  * The price of an individual drink.
  * The total price of an order.
* Pricing should be configurable and maintained separately from the drink definition.
* Everything should run entirely in memory.

## Constraints

* Use plain classes and objects only.
* No databases.
* No APIs.
* No frameworks.
* No external libraries.
